- ETL 仍为 12,907 条观测，2018-01 至 2026-09，420 条至少触发一个质量标记；12,487 是全时期排除标记后的数目，不是每页统一样本数。

- 新 Notebook 04 使用截至 2024-05 的 9,414 条无质量标记观测生成画像，StandardScaler 和 KMeans 只拟合该时期。聚类汇总晚点率则用同一时期 ML 有效目标样本，两种筛选不能混用。
- 新聚类晚点率已改为 >15 分钟晚点数之和 / 实际开行数之和；它仍不等于已确认定义的官方到达晚点率。原因画像仍是原始百分比的简单平均，页面仅在技术详情展示，不当作总体原因占比。
- 新 Notebook 05：训练 2019-01 至 2024-05，验证 2024-06 至 2025-06，测试 2025-07 至 2026-09。A/B/C/D 与朴素预测共用 1,857 条测试观测。图特征在验证时用训练集构造，在最终测试时用训练+验证构造。
- 历史滚动特征使用过去月份；这属于随月份推进的评估，不是从一个固定日期一次预测整个测试期。代码审查支持训练期边界的改进，但不替代完整数据可用性和产物溯源审计。
- 不采用旧方案里的 R² 0.4513/0.4595 作为本次结论。以导出预测重新校验的实际结果为准。
