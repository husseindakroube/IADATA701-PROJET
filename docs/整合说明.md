## 必须区分的口径

- 当前 ETL 是 12,907 条记录，覆盖 2018-01 至 2026-09。
- 四种质量标记合计涉及 420 条独立观测；ETL 本身不删除它们。
- 12,487 是排除这些观测后的数量，不能当成所有页面共同的数据量。
- 描述性页面使用“方向 + 服务类型”定义线路；聚类 CSV 的 65 条是合并双向的站点对。
- 现有 ML 目标为“超过15分钟晚点数 /（计划数−取消数）”。这不是已经确认的统一到达晚点率。
- 同学的聚类 Notebook 又使用了不同分母的晚点率。未把这些不一致的比率复制为正式结论。
- 图表和聚类只读取已有产物；页面切换不会训练模型或执行 Notebook。
